      What the stream is about

      A small local AI does not know every game or show and may invent details. The lookup fetches a short summary from Wikipedia (only these search words leave your PC) and the bot treats it as background facts. Check the matched page above: if it is the wrong one, add search words and look again, or write your own notes (those are never replaced). Saved here, it wins over the setting in the .env file.

      Add a YouTube stream

      A video link is checked cheaply every minute. A channel link finds that channel’s live stream through YouTube’s search, which has a small daily allowance, so it is checked only every 15 minutes or so. Channel names like @name cannot be looked up: open the channel and copy its youtube.com/channel/UC... address. Only add streams you own or have the owner’s permission to chat in.

      Kick: the bot can only read chat on the channel of the account it is signed in with (Kick’s rule for this kind of sign-in), so that channel is always on the list and other Kick channels cannot be added.

      Fail-safe

      The safety rules (no links, no commands, no personal data, bot disclosure) are built into the program and are added to every prompt automatically, so editing a prompt cannot switch them off.

      AI model

      Models come from Ollama on this PC. Install a new one with ollama pull NAME, then reload the list. A model is tested before it takes over; if the test fails the old one stays.

      Generation settings

      A bigger context window needs more GPU memory: this PC has 4 GB, and the measured setup uses 4096. Changing it makes Ollama reload the model once (a slow first reply). On battery the AI is much slower, so keep the timeout generous unless you stream plugged in.

      Proactive chat

      MinMax Chat is quiet after (minutes) Gap after any bot message (minutes)

      Each activity repeats at a random time between its min and max, but only while chat has been quiet, and never straight after another bot message. Viewers always come first.

      Message limits per platform

      Limits protect the chat from the bot. YouTube also has a daily quota that allows roughly 200 messages per 6-hour stream, so the YouTube default (7 per 10 minutes) is deliberately low. These numbers are not platform guarantees: check how your chat reacts.
